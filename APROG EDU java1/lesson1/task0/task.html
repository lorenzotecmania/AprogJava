Lesson java1:

SPECIFIC GOALS:

The students should be able to:

    Analyze and understand:
        Java codification
        Input / Output data
        Flow control instructions

    Document a program:
        Using appropriate Identifiers
        Using appropriate output messages
        Using only essential comments

    Solve a problem by:
        Analyzing it
        Designing the algorithmic solution
        Codifying it in Java
        Testing the solution.

    Given an algorithm, describe its functionality and adapt it to new specifications;
